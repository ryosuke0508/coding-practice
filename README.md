# coding-practice

paiza / AtCoder などで解いてきたJavaのコードや、Java学習用のメモを格納するリポジトリです。

## 構成

```
coding-practice/
├── TODO.md             # 今後学習予定のトピック
└── java-notes/          # テーマ別のJava学習ノート
    ├── 01_標準入力基礎/
    ├── 02_構造体/
    ├── 02-2_構造体のリスト/
    ├── 03_Mapのソート/
    ├── 04_HashSet/
    ├── 05_Setの挿入と削除/
    ├── 06_配列の挿入/
    ├── 07_ソート問題/
    ├── 08_再帰_キャンディー配布/
    ├── 09_アルファベットポーカー/
    ├── 10_ドーナツ探し/
    ├── 11_山頂探索/
    ├── 12_地図移動シミュレーション/
    ├── 13_計量スプーン計算/
    ├── 14_お釣り硬貨枚数計算/
    ├── 15_水を入れるゲーム_bit全探索/
    ├── 16_盤面反転_配列のマッピング/
    └── 17_回転寿司連続K枚_循環配列/
```

各フォルダには `Main.java`（解答コード）を格納しています。paiza形式の問題を解いたものには、問題文を `problem.md` として合わせて格納しています。
